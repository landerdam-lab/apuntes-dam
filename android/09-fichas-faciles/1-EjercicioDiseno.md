# 📄 1-EjercicioDiseno

## En resumen
Es el enunciado de un ejercicio: hay que recrear un menú de "agenda de contactos" con un aspecto concreto (fondo azul claro, sombra en los textos, botones que cambian de imagen al pulsarlos, sin barras arriba) siguiendo una imagen de ejemplo.

## Puntos clave explicados fácil
1. El fondo de toda la app debe ser de un color concreto (un azul clarito).
2. Los textos que van debajo de cada botón deben llevar una sombra (como si tuvieran relieve), y hay que crear "plantillas de estilo" reutilizables para no repetir el mismo código de sombra una y otra vez.
3. Cada botón debe tener dos imágenes: una normal y otra para cuando se está pulsando, cambiando automáticamente entre las dos.
4. La app no debe mostrar ni la barra de título ni la barra de notificaciones — debe verse a pantalla completa.
5. Al tocar el botón "Nuevo" debe abrirse una pantalla nueva.
6. El diseño tiene que adaptarse bien a distintos tamaños de pantalla, no quedar fijo a un tamaño concreto.
