# Apuntes DAM

Vault de Obsidian con los apuntes del ciclo **DAM**. Abre **esta carpeta** (`apuntes-dam`) como vault en Obsidian.

| Módulo | Portada |
|---|---|
| 📱 Android (PMDM / Diseño de interfaces) | [android/INICIO.md](android/INICIO.md) |

## Estructura

```
apuntes-dam/
├── README.md        ← esta portada
├── CLAUDE.md        ← normas del repositorio
├── .obsidian/       ← configuración del vault (enlaces relativos, colores del grafo)
└── android/         ← apuntes, PDFs y código de Android → empieza en android/INICIO.md
```

Los enlaces entre notas son enlaces Markdown **relativos**, así que funcionan igual en Obsidian que en GitHub.
